# Software

## Overview

The software part of the project handles the processing of the information received from the hardware and supports the safety logic of the system.

Depending on the prototype implementation, the software can handle:

* Sensor data processing
* Object information
* Vehicle information
* TTC calculation
* Risk assessment
* Warning generation
* Event logging
